# Software Engineering Lab

**Problem Statement:** #43 - Feature Flag & Dynamic Config Manager
**SRN:** PES1UG24AM267  

### Project Overview

The system is a centralized platform for managing feature flags and dynamic configurations. It supports percentage-based rollouts, environment-specific overrides, and synchronization of flag states with client SDKs.

- Release Manager
