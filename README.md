## Feature Flag & Dynamic Config Manager

This repository contains the requirements engineering and UML use-case modelling work for the Feature Flag & Dynamic Config Manager.

### Project Overview

The system is a centralized platform for managing feature flags and dynamic configurations. It supports percentage-based rollouts, environment-specific overrides, and synchronization of flag states with client SDKs.

### Actors

- Software Engineer
- Release Manager

### Deliverables

1. **Requirements Table** – Contains 5 Functional Requirements and 2 Non-Functional Requirements.
2. **UML Use-Case Diagram** – Shows the system actors, use cases, and include/extend relationships.
3. **Use-Case Flow Specification** – Describes the Evaluate Feature Flag use case, including preconditions, postconditions, main success scenario, and alternate flow.

For the three deliverables, refer to **`AM267_Lab1_document.pdf`** included in this repository.
